# Hydrologic Analysis
### This project explores watershed delineation in ArcGIS Pro.
#### Running tools such as fill, flow accumulation, and flow direction on the DEM raster, you can delineate a watershed from a certain pour point. Taking the 10m DEM raster, you can pick a pour point and determine the stream network of any watershed.
<img width="640" height="782" alt="unnamed" src="https://github.com/user-attachments/assets/9c2b1e87-9ad6-402a-aec8-914a43cbe082" />

#### I found the intricacies of the flow direction raster very curious because it is created using the DEM, and while the 10m DEM I used displayed certain areas as one color, the flow direction showed more slopes, rivers, and even streets and buildings. This makes it clear that the DEM was collected using lidar because the returns will capture fine details in the terrain. I also observed that flow direction almost exactly matched the aspect direction. This makes sense because if a slope is facing a certain direction, the water will also flow that direction. From there the flow accumulation used the direction and the DEM to pick out only stream networks. I chose the area to delineate a watershed based off the base map where I could see a canyon and where I guessed an intricate stream network would be. I was surprised to find that after running flow accumulation, it did not show many streams in that area, and only when my flow accumulation threshold was quite high did it display a greater network.
#### Secondarily, from this exercise I learned more about how the symbology type of a raster can drastically change how the data is displayed. For example, because the flow accumulation raster covered such a large area and had a large range of values, to symbolize using only minimum and maximum values was not sufficient. When changing the display to use standard deviations it becomes much more clear because the rivers are only found in the upper most values. Additionally, when extracting the slope by the mask of the watershed polygon, classifying the slope rather than stretching makes it much easier to interpret.
